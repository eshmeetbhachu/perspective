# Technology Selection

Why each major technology was chosen, and what else could have been used. Facts come from the Decision Log; where the log is silent, the reasoning is marked **(reconstructed)**.

| Technology                                            | Chosen because                                                                                                                                                                                                             | Main alternatives                                          | Why not those                                                                                                                                                              |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TypeScript everywhere** (D1)                        | One language for browser and server; types shared through `packages/shared`; the compiler catches whole classes of bugs before running                                                                                     | JavaScript; Python/Go backend                              | Plain JS loses the shared types; a second language doubles what has to be learned and makes sharing rules impossible                                                       |
| **TypeScript 6.0.x** (D18)                            | typescript-eslint's type-aware rules don't support TypeScript 7 (the Go rewrite) yet                                                                                                                                       | TypeScript 7                                               | Faster type-checking, but the lint rules that catch un-awaited promises would stop working. Revisit when supported                                                         |
| **pnpm workspaces**                                   | Strict dependency isolation (a package can only import what it declares), a fast content-addressed store, first-class workspaces, release-age policy                                                                       | npm workspaces, Yarn, Turborepo/Nx                         | npm allows "phantom" imports of undeclared packages; Turborepo/Nx add build orchestration this size doesn't need **(reconstructed)**                                       |
| **React + Vite** (D1)                                 | The most widely used UI library; Vite's dev server starts instantly and its proxy solves the one-origin requirement                                                                                                        | Next.js, Vue, Svelte                                       | Next.js adds server rendering and its own server, which would duplicate the Fastify API **(reconstructed)**                                                                |
| **React Router (declarative `<Routes>`)**             | Standard client routing; nested layouts and an `<Outlet />` for guards                                                                                                                                                     | TanStack Router                                            | React Router is more widely known **(reconstructed)**                                                                                                                      |
| **TanStack Query**                                    | Server state solved: caching, deduplication, infinite queries, mutations, polling                                                                                                                                          | Redux Toolkit Query, SWR, hand-written `useEffect` fetches | `useEffect` fetching re-implements loading/error/caching badly; RTK Query brings Redux along **(reconstructed)**                                                           |
| **Fastify** (D1)                                      | Fast, schema-first (validation and serialisation are part of a route), first-class hooks, a built-in logger (Pino), `inject()` for tests, encapsulated plugins                                                             | Express, NestJS, Hono                                      | Express has no built-in validation, schemas or typed hooks; NestJS adds heavy decorators and dependency injection; Hono targets edge runtimes **(reconstructed)**          |
| **Zod + fastify-type-provider-zod** (D20)             | One schema = runtime validation + TS type; reusable in React forms; the most transferable skill                                                                                                                            | TypeBox (Fastify-native, faster), Joi, Yup                 | Validation cost measured at ~2% of CPU in Phase 9, so the speed advantage didn't matter                                                                                    |
| **PostgreSQL 18** (D2, D26)                           | Relational data (users → posts → votes → challenges → comments); transactions, constraints, partial and expression indexes, recursive CTEs, full-text search, trigram extension, JSON. Version 18 adds built-in `uuidv7()` | MySQL, MongoDB, SQLite                                     | MongoDB lacks multi-document constraints and joins that this data needs; SQLite doesn't suit a networked multi-instance server; MySQL lacks partial indexes and `uuidv7()` |
| **Drizzle ORM**                                       | Type-safe queries that look like SQL; schema in TypeScript; migrations generated from the schema; drops to raw `sql\`\`` easily; light runtime                                                                             | Prisma, Kysely, raw `pg`                                   | Prisma has its own query engine and schema language, and makes raw SQL awkward; raw `pg` loses types **(reconstructed)**                                                   |
| **node-postgres (`pg`)**                              | The standard Postgres driver; connection pool                                                                                                                                                                              | postgres.js                                                | Both fine; `pg` is the default for Drizzle's node-postgres adapter **(reconstructed)**                                                                                     |
| **argon2id via @node-rs/argon2** (Security checklist) | The OWASP-recommended password hash; memory-hard (expensive on GPUs); Rust native binding is fast and has no build step                                                                                                    | bcrypt, scrypt, PBKDF2                                     | bcrypt has a 72-byte input limit and is not memory-hard; PBKDF2 is cheap on GPUs                                                                                           |
| **Session cookies** (D12)                             | Revocable instantly; unreadable by JavaScript                                                                                                                                                                              | JWT in localStorage                                        | See [AUTHENTICATION_DECISIONS.md](AUTHENTICATION_DECISIONS.md)                                                                                                             |
| **openid-client** (D34)                               | A certified OpenID Connect library: state, PKCE, nonce, ID-token signature/issuer/audience/expiry checks                                                                                                                   | Passport.js, hand-rolled OAuth, Auth.js                    | Hand-rolled crypto is where security bugs live; Passport is callback-based and loosely typed **(reconstructed)**                                                           |
| **nodemailer over SMTP** (D59)                        | Any provider works through one `SMTP_URL`; switching is a config change                                                                                                                                                    | A provider's HTTP API (Resend, SendGrid SDK)               | Lock-in to one provider's SDK                                                                                                                                              |
| **Pino**                                              | Fastify's built-in logger; structured JSON; redaction support                                                                                                                                                              | Winston                                                    | Pino comes with Fastify and is faster                                                                                                                                      |
| **marked + DOMPurify** (D42)                          | Markdown keeps editing lossless; DOMPurify is the de-facto HTML sanitiser, with an allowlist                                                                                                                               | Store HTML; react-markdown; server-side sanitising         | Stored HTML can't be re-rendered with new rules; an allowlist sanitiser protects even if the Markdown parser has a bug                                                     |
| **Vitest**                                            | Same config style as Vite; fast; Jest-compatible API                                                                                                                                                                       | Jest                                                       | Jest's ESM and TypeScript support needs more setup **(reconstructed)**                                                                                                     |
| **Playwright** (D53)                                  | Real browsers, auto-waiting, traces on failure, starts the servers itself (`webServer`)                                                                                                                                    | Cypress, Selenium                                          | Cypress runs inside the browser with limits on multiple tabs/users; Selenium is lower level **(reconstructed)**                                                            |
| **Docker + Compose**                                  | Same Postgres version everywhere (dev, CI, lab); production image identical to what CI builds                                                                                                                              | Installing Postgres natively                               | Version drift between machines; harder to reset                                                                                                                            |
| **esbuild** (D56)                                     | Bundles the API and the TS-source shared package in milliseconds                                                                                                                                                           | tsup, tsc emit                                             | `tsc` can't follow the `.ts` export of shared without project references **(reconstructed)**                                                                               |
| **Redis + ioredis** (D67, D68)                        | In-memory store for cache, shared rate limits, queue, positions                                                                                                                                                            | Memcached, Postgres-based cache                            | Redis also supports Lua scripts (atomic bump), BullMQ and rate-limit stores                                                                                                |
| **BullMQ** (D70)                                      | Mature Redis-backed queue: retries, backoff, concurrency, separate workers                                                                                                                                                 | pg-boss (Postgres queue), RabbitMQ                         | pg-boss would avoid Redis but puts queue load on the database; RabbitMQ is another service **(reconstructed)**                                                             |
| **k6** (D65)                                          | Scriptable load tests in JavaScript with arrival-rate scenarios                                                                                                                                                            | Artillery, JMeter, wrk                                     | k6's constant-arrival-rate model and checks fit "visits per second" experiments **(reconstructed)**                                                                        |
| **Prometheus + Grafana** (D73)                        | The standard for metrics; dashboards provisioned from the repo                                                                                                                                                             | Datadog, New Relic                                         | Paid, and the lab must run offline                                                                                                                                         |
| **OpenTelemetry + Jaeger** (D73)                      | Vendor-neutral tracing standard                                                                                                                                                                                            | Vendor agents                                              | Lock-in                                                                                                                                                                    |
| **Vercel / Render / Neon / Brevo** (D63)              | All free with no card; constraints matched (Vercel's 120 s proxy timeout ≥ Render's wake-up; Brevo's port 2525 not blocked by Render)                                                                                      | Koyeb, Netlify, Fly.io, Railway, Supabase, Gmail SMTP      | Koyeb closed its free plan; Netlify's proxy times out at 26 s; others need a card or have no free tier **(partly reconstructed)**                                          |
